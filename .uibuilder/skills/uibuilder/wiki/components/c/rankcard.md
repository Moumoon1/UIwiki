# rankCard

规范组件名：`rankCard`

用于榜单列表、排行榜、排名列表、收益排行或作品排行。

## Variants

| Variant | 说明 |
|---------|------|
| `showAll` | 平铺展示全部榜单（默认） |
| `showMore` | 折叠展示，点击展开更多 |
| `vote` | 可点击投票或助力的榜单 |

默认使用 `showAll`。榜单条目较多时选择 `showMore`，需要互动投票/助力时选择 `vote`。

被用于：

- [C端榜单页](../../pages/c/leaderboard.md)
- [C端活动页](../../pages/c/campaign.md)
