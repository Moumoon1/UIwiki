# 页面搭建流程

默认最终产物是 Figma 画布上的页面设计稿。

## 轻量拼接模式

满足以下条件时，直接使用轻量拼接模式：

1. 用户已经明确要哪些页面，或明确给出页面内模块/组件顺序。
2. 页面只是把已批准组件在同一个画布 Frame 内纵向排列。
3. 每个模块都能在对应组件目录中找到已批准组件。
4. 不需要记录复杂业务规则、状态矩阵、组件缺口或交付给他人复用的规格文件。

执行方式：

1. 判断 B 端或 C 端。
2. 读取对应组件目录。
3. 在内部维护最小清单：页面名称、组件顺序、全宽/内容区布局标记。
4. 创建目标 Frame。
5. 按顺序插入真实 Figma 组件实例。
6. 只调整组件实例之间的外部布局，不修改组件内部结构和样式。
7. 返回画布位置或链接。

轻量拼接模式不得输出或保存完整 `*-spec.json`。

## 完整规格模式

出现以下任一情况时，升级为完整规格模式：

- 需要 AI 推断页面模式。
- 存在组件缺口。
- 需要新增页面模式之外的模块。
- 包含复杂业务规则、状态矩阵、表单字段或数据结构。
- 用户明确要求 JSON、规格、验收清单或可复用方案。
- 当前没有可用画布工具，只能退化为搭建步骤。

完整规格模式使用 [页面规格校验](./validate-page-spec.md)。
